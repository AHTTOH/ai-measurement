# shared · 공통 스키마와 설정 항목 형식

> 최초 작성: 2026-09-27 · 마지막 갱신: 2026-09-27

## 담는 것

| 위치 | 담는 것 |
|---|---|
| `src/exam-package/` | 시험 패키지 스키마 v1(`exam.json`, `grading.json`, 루브릭, 정답 메타)과 파일 간 교차 검증 |
| `src/api/` | 서버·웹이 함께 쓰는 API 요청 스키마와 응답 타입 |
| `src/detection/` | 개인정보 패턴·자료 값 지문 탐지(서버 기록과 채점이 같은 함수를 쓴다) |
| `src/notices/` | 공지 노출 시각 계산 |
| `src/answers/` | 답안 형식 검증 |
| `src/node/` | Node 전용: 패키지 폴더 읽기, CSV 처리, 자료 해시 대조, 정규식 ReDoS 검사. 웹에서 import하지 않는다(`@ai-measurement/shared/node`) |

## 규칙

- 이 폴더는 형식을 정의한다. 실제 값은 시험 패키지(`exams/`)와 환경 설정에서 온다.
- 필수 값이 비어 있으면 기본값으로 채우지 않고 검증 단계에서 거부한다.
- 이 폴더는 server·web·grading 어느 쪽도 import하지 않는다. 의존 방향은 그쪽에서 이쪽 하나뿐이다.
- 탐지 정규식은 응시자 메시지마다 서버에서 돌므로, 등록 시 ReDoS 검사를 통과해야 한다.
