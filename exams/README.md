# exams · 시험 패키지

> 최초 작성: 2026-09-27 · 마지막 갱신: 2026-09-27

시험 하나가 폴더 하나다(`exams/<slug>/`, 폴더 이름과 `exam.json`의 slug가 같아야 한다). 시험 내용의 진실의 원천이며, 서버와 채점은 이 폴더를 읽기만 한다.

## 패키지 구성 (스키마 v1, 형식의 원본은 `shared/src/exam-package/`)

| 파일 | 담는 것 | 응시자 노출 |
|---|---|---|
| `exam.json` | 시험 정의: 시간, 토큰 예산, 컨텍스트 상한, 응시용 AI 설정, 축 가중치, 위반 처리 기준, Case·하위문항·자료·공지 | 일부(문항·자료·공개된 공지) |
| `grading.json` | 채점 설정: 루브릭 버전, 채점 모델, 태그 정책(중대 여부), 개인정보 탐지 정규식 | 안 됨 |
| `rubrics/<caseKey>.json` | Case별 축마다 규칙과 LLM 기준, 배점 | 안 됨 |
| `answer-keys/<caseKey>.json` | 자료의 컬럼·행·쪽 태그와 지문, 선택형 정답, 기준답안 | 안 됨 |
| `materials/` | 응시자에게 주는 CSV·PDF | 됨 |

## 규칙

- 실제 시험 패키지는 커밋하지 않는다. 정답·루브릭 유출을 막기 위해서다. 커밋하는 것은 `sample-`로 시작하는 샘플 시험뿐이다.
- 등록 전에 `npm run exam:validate -- exams/<slug>`로 검증한다. 스키마, 파일 간 참조, 자료 내용(CSV 헤더·행, PDF 쪽수), 탐지 정규식의 ReDoS 위험을 모두 본다.
- 자료 속 개인정보는 전부 가공 데이터로 만든다. 실존 인물 데이터가 Claude API로 나가면 안 된다.
- 등록한 뒤 자료 파일을 바꾸면 해시가 달라져 서버가 그 자료를 쓰지 않는다. 바꾸려면 초안 상태에서 다시 등록하거나 slug를 바꿔 새 시험으로 등록한다.
- `sample-ai-practice`는 `npm run exam:build-sample`이 만든다. 손으로 고치지 말고 `scripts/sample-exam-package/`를 고친다.
