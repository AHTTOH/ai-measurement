# grading · 자동채점

> 최초 작성: 2026-09-27 · 마지막 갱신: 2026-09-27

## 구성 (PRD 10장의 세 축)

| 위치 | 담는 것 |
|---|---|
| `src/context/` | 종료된 세션 하나의 채점 입력(메시지, 실제 전송 본문, 첨부, 답안 버전) 읽기 |
| `src/rules/` | 결정적 규칙 판정: 선택형 정답, 필요 컬럼 전달, 컬럼·행·쪽 유출, 개인정보 패턴, 공지 이후 수정 |
| `src/llm/` | LLM 채점: 프롬프트, 구조화 출력 스키마·검증, Anthropic(즉시·배치)·모의 구현 |
| `src/aggregate/` | 축별 득점률·가중 총점, 중대 보안 위반 기록 |
| `src/job/` | 채점 작업 큐 처리(`FOR UPDATE SKIP LOCKED`), 세션별 결과 저장 |
| `src/worker-main.ts` | 채점 워커 진입점(`npm run start:worker`) |

## 규칙

- API 서버 없이 DB와 `exams/`만으로 실행된다.
- 채점 결과는 루브릭 버전·채점 방식·모델 ID와 함께 저장한다. 같은 작업을 다시 돌리면 그 작업의 결과만 교체한다.
- 즉시 모드는 세션 단위로 저장해, 워커가 중간에 멈춰도 끝난 세션의 LLM 호출을 되풀이하지 않는다.
- 파싱 실패·근거 누락은 '미채점'으로 드러낸다. 0점이나 평균으로 채우지 않는다. 미채점 항목이 있는 축과 총점은 null이다.
- 배점·규칙·허용오차는 시험 패키지에서 읽는다. 코드에 상수로 두지 않는다.
- 작업의 채점 공급자(anthropic·mock)가 워커 설정과 다르면 작업을 실패로 남긴다.
