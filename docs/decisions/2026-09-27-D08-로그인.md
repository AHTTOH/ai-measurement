# 결정 D8: 응시자 로그인

> 결정일: 2026-09-27 · 결정자: 신영환 · 기록: Claude (Opus 5.5 세션)
> 근거: 2026-09-27 신영환 지시 "작업 다 시작해". 구현계획 0장 권장안 채택.

## 결정

- 응시번호 + PIN으로 로그인한다. PIN은 관리자가 발급하고 발급 화면에서 한 번만 보여준다. DB에는 해시만 저장한다.
- 같은 응시번호로 다시 로그인하면 이전 로그인 세션을 끊고 감사 로그를 남긴다.
- 세션 토큰은 httpOnly 쿠키로 준다.
- 관리자는 별도 계정(아이디 + 비밀번호)으로 로그인한다. 계정은 스크립트로 만든다.
