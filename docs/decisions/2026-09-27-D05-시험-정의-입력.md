# 결정 D5: 시험 정의 입력 방식

> 근거: 2026-09-27 신영환 지시 "작업 다 시작해". 구현계획 0장 권장안 채택.

## 결정

- 시험은 시험 패키지(정의 JSON + 자료 + 루브릭 + 정답 메타)로 만든다.
- 관리자 화면에서 zip 업로드 또는 서버의 `exams/` 폴더 선택으로 등록한다. 등록 전에 스키마와 파일 무결성을 검증한다.
- 등록한 시험 정의는 DB에 불변 스냅샷으로 저장한다. 자료 파일은 해시를 기록해 두고 읽을 때마다 대조한다.
- 웹 폼 편집기는 MVP에서 뺀다.
