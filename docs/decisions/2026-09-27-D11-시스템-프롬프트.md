# 결정 D11: 응시용 AI의 시스템 프롬프트

> 결정일: 2026-09-27 · 결정자: 신영환 · 기록: Claude (Opus 5.5 세션)
> 근거: 2026-09-27 신영환 지시 "작업 다 시작해". 구현계획 0장 권장안 채택.

## 결정

- 시스템 프롬프트는 중립으로 둔다. 시험 부정 방지 문구만 넣고, Prompt Injection 방어 문구는 넣지 않는다.
- 이유: 자료 속 인젝션 문자열을 걸러내는 것이 응시자의 평가 대상(정보 판단)이기 때문이다.
- 시스템 프롬프트는 시험 패키지에 있고, 시험 전체에서 바이트 단위로 동일하다. 날짜·응시번호·Case 이름을 넣지 않는다.
