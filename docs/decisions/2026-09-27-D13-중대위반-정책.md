# 결정 D13: 중대 보안 위반의 처리 기준

> 결정일: 2026-09-27 · 결정자: 신영환 · 기록: Claude (Opus 5.5 세션)
> 근거: 2026-09-27 신영환 지시 "작업 다 시작해". 구현계획 0장 권장안 채택.

## 결정

- 처리 기준은 시험마다 시험 패키지의 `violationPolicy`로 정한다. 값은 셋 중 하나다.
  - `flag_only`: 점수는 그대로, 플래그만 표시
  - `review`: 결과를 검토 대기로 표시
  - `fail`: 위반 1건 이상이면 불합격 표시
- 어떤 태그가 중대 위반인지는 시험 패키지의 태그 정책에서 정한다.
