# 결정 D10: 채점 모델과 실행 방식

> 결정일: 2026-09-27 · 결정자: 신영환 · 기록: Claude (Opus 5.5 세션)
> 근거: 2026-09-27 신영환 지시 "작업 다 시작해". 구현계획 0장 권장안 채택.

## 결정

- 채점은 시험 종료 후 관리자가 실행한다. 채점 작업은 큐에 들어가고 채점 워커가 처리한다.
- LLM 채점은 Message Batches(비용 50%)를 기본으로 하고, 즉시 모드도 둔다. 모드는 채점 실행 시 고른다.
- 채점 모델은 `claude-sonnet-5`로 시작한다. 골든 세트 검증 후 상위 모델 승격을 검토한다. 모델은 설정값이다.
- 채점 결과는 구조화 출력으로 받고, 파싱 실패는 미채점으로 드러낸다.
