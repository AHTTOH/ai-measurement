# 결정 D3: 자료를 AI에 전달하는 방식

> 결정일: 2026-09-27 · 결정자: 신영환 · 기록: Claude (Opus 5.5 세션)
> 근거: 2026-09-27 신영환 지시 "작업 다 시작해". 구현계획 0장 권장안 채택.

## 결정

- 붙여넣기와 파일 첨부를 모두 허용한다.
- CSV 첨부는 컬럼과 행을 골라 보낸다. PDF 첨부는 전체 또는 페이지 범위를 고른다.
- 서버가 선택 결과로 실제 전송 본문을 만들고, 무엇을 보냈는지 첨부 기록으로 남긴다.
- 붙여넣은 본문도 채점 시 자료의 값 지문과 대조해 어떤 컬럼·행이 넘어갔는지 판정한다.
