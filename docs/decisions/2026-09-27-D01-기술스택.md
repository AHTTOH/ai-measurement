# 결정 D1: 기술 스택

> 결정일: 2026-09-27 · 결정자: 신영환 · 기록: Claude (Opus 5.5 세션)
> 근거: 2026-09-27 신영환 지시 "작업 다 시작해". 구현계획 0장 권장안을 채택했다.

## 결정

| 영역 | 선택 | 이유 |
|---|---|---|
| 언어·런타임 | TypeScript(strict), Node.js 24 | server·web·grading이 스키마 정의 하나를 공유 |
| 패키지 구성 | npm workspaces: `shared`, `infra`, `server`, `grading`, `web` | 승인된 최상위 폴더를 그대로 패키지 경계로 쓴다 |
| API 서버 | Hono + @hono/node-server, 상주형 단일 프로세스 | 120분 세션과 SSE 스트리밍. 서버리스 제외 |
| 입력 검증 | zod | 시험 패키지·API 요청·환경변수 검증을 한 도구로 |
| DB | PostgreSQL | 토큰 원장 차감을 행 잠금 트랜잭션으로 처리 |
| 로컬 DB | embedded-postgres(실제 PostgreSQL 바이너리를 npm으로 받아 실행) | 이 PC에 PostgreSQL·Docker가 없다. 설치 권한 없이 실제 엔진으로 개발·테스트 |
| ORM·마이그레이션 | Drizzle ORM + drizzle-kit | 타입이 있는 스키마, SQL 마이그레이션 파일 생성 |
| 작업 큐 | PostgreSQL 테이블 + `FOR UPDATE SKIP LOCKED` | 인프라를 늘리지 않는다 |
| 웹 | React + Vite + React Router, CSS 변수 토큰 | 응시자·관리자 두 화면 |
| AI 호출 | @anthropic-ai/sdk. 호출부는 게이트웨이 인터페이스 뒤에 둔다 | 실제 구현과 모의 구현을 설정으로 교체 |
| 파일 처리 | csv-parse·csv-stringify, pdf-lib, fflate | CSV 컬럼·행 선택, PDF 페이지 추출, 패키지 zip 업로드 |
| 테스트 | Vitest, Playwright | 단위·통합·e2e |

## 제약

- AI 응답 스트리밍의 진행 상태를 서버 메모리에 둔다. 따라서 API 서버는 단일 인스턴스로 운영한다. 여러 대가 필요해지면 새 결정으로 바꾼다.
- 운영 DB는 별도 PostgreSQL 인스턴스에 연결한다. embedded-postgres는 개발·테스트 전용이다.
  - 2026-09-27 갱신: `DATABASE_URL` 하나 대신 프로세스별 DB 계정으로 접속한다(`docs/decisions/2026-09-27-권한-구조-분리.md`).
  - 2026-09-27 갱신: 운영 DB는 Supabase로 정했다(`docs/decisions/2026-09-27-D17-DB-Supabase.md`).
