# 결정: API 키 발급 전 모의 AI 게이트웨이로 개발

> 결정일: 2026-09-27 · 결정자: 신영환 · 기록: Claude (Opus 5.5 세션)
> 근거: 2026-09-27 신영환 지시 "api는 나중에 줄라니까 나머지먼저 작업해. 그거 결제해야함".

## 결정

- Anthropic API 연동 코드는 공식 SDK 문서대로 작성하되, 실제 호출 검증은 API 키 결제 후에 한다.
- 그전까지는 모의 게이트웨이로 개발·테스트한다.
- 모의 구현은 환경변수 `AI_PROVIDER=mock`, `GRADING_LLM_PROVIDER=mock`을 명시했을 때만 켜진다. 기본값은 없다. 값이 없으면 서버가 기동을 거부한다.
- 모의 결과는 DB와 화면에 모의임을 표시한다. 모의 채점 점수를 실제 점수로 오인하지 않게 하기 위해서다.

## 보류된 항목

- D15(조직 사용 티어 확인)와 P0 스파이크 1(토큰 계산·캐시 적중 실측)은 API 키 발급 후 진행한다.
