# 결정 D2: 입력 토큰의 정의

> 결정일: 2026-09-27 · 결정자: 신영환 · 기록: Claude (Opus 5.5 세션)
> 근거: 2026-09-27 신영환 지시 "작업 다 시작해". 구현계획 0장 권장안 채택.

## 결정

- 토큰 원장에서 차감하는 양은 **응시자가 새로 보내는 메시지 하나(본문 + 첨부)** 의 토큰 수다.
- 전송 전에 실제 호출 모델과 같은 모델로 토큰 계산 API를 호출해 센다.
- 대화 이력 재전송분, 캐시 읽기·쓰기, 출력 토큰은 차감하지 않는다. API가 돌려준 usage는 비용 모니터링용으로 메시지에 따로 저장한다.
- 토큰 계산에 실패하면 전송을 막고 오류를 드러낸다. 추정치로 대신하지 않는다.

## 이유

PRD 6장 예시("8,000 소비 후 3,000 소비, 누적 11,000")가 신규 전송분만 세는 모델과 맞는다.
