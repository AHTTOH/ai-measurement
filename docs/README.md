# docs · 문서

> 최초 작성: 2026-09-27 · 마지막 갱신: 2026-09-27

| 위치 | 담는 것 | 파일명 |
|---|---|---|
| `PRD.md` | 제품 요구사항 원본 | 고정 |
| `plan/` | 구현계획 | `YYYY-MM-DD-<주제>.md` |
| `decisions/` | 확정된 결정. 한 결정에 한 파일. 확정 후에는 고치지 않고, 번복은 새 파일로 남긴다 | `YYYY-MM-DD-<주제>.md` |
| `audit/` | 점검·스파이크·부하·채점 검증 리포트. 시각 리포트는 같은 이름의 `.html`을 나란히 둔다 | `YYYY-MM-DD-<주제>.md` / `.html` |
| `runbook/` | 시험 당일 운영 절차 | `<절차명>.md`, 문서 안에 갱신 날짜 |

## 규칙

- 모든 문서 상단에 최초 작성일과 마지막 갱신일을 절대 날짜로 적는다.
- 상대 날짜(어제, 지난주)는 쓰지 않는다.
- 폴더·파일 목록을 문서에 베끼지 않는다. 목록은 `ls`로 확인한다.
