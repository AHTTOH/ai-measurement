# 배포 절차 (Firebase Hosting + Cloud Run)

> 최초 작성: 2026-09-27 · 마지막 갱신: 2026-09-27
> 대상: 코드를 고친 뒤 운영에 반영하는 사람. 구성과 이유는 `docs/decisions/2026-09-27-D18-호스팅-Firebase.md`.
> 필요한 도구: gcloud(ssyh97@gmail.com 로그인), firebase CLI. 저장소 루트에서 Git Bash로 실행한다.

## 1. 이미지 빌드 (약 1분 30초)

```bash
P=draw-quiz-prod2
IMG=asia-northeast3-docker.pkg.dev/$P/aim/app:$(date +%Y%m%d-%H%M%S)
gcloud builds submit --config infra/deploy/cloudbuild.yaml --substitutions=_IMAGE=$IMG --project $P --region=asia-northeast3 .
```

업로드 대상은 `.gitignore`를 따른다. `.env`, `workspace/`, 실제 시험 패키지는 올라가지 않는다.

## 2. 서버 배포

```bash
bash infra/deploy/deploy-cloud.sh "$IMG"
```

수험생 서버·관리자 서버·채점 워커를 차례로 올린다. 시크릿은 Secret Manager에서 읽는다.

## 3. 웹 배포

```bash
bash infra/deploy/deploy-hosting.sh
```

## DB 스키마를 바꿨을 때

배포 전에 로컬에서 `npm run db:migrate`를 먼저 돌린다(`.env`가 Supabase를 가리킨다). 새 테이블이면 역할별 권한 마이그레이션도 함께 만든다.

## 시크릿 바꾸기

```bash
printf '%s' '새 값' | gcloud secrets versions add aim-anthropic-api-key --data-file=- --project draw-quiz-prod2
bash infra/deploy/deploy-cloud.sh "$IMG"   # 새 버전을 읽도록 다시 배포
```

DB 로그인 비밀번호를 바꾸면 `.env`를 고치고 `npm run db:logins`로 DB에 적용한 뒤, 해당 시크릿도 같은 값으로 바꾼다.

## 시험 패키지 올리기

관리자 화면의 zip 업로드는 버킷(`aim-exams-draw-quiz-prod2`)에 저장되어 세 서비스가 함께 본다. 직접 올리려면:

```bash
gcloud storage cp -r exams/<slug> gs://aim-exams-draw-quiz-prod2/
```

## 시험이 없는 기간에 비용 줄이기

```bash
gcloud run services update aim-candidate --min-instances 0 --region asia-northeast3 --project draw-quiz-prod2
gcloud run services update aim-grading --min-instances 0 --region asia-northeast3 --project draw-quiz-prod2
```

시험 전날 `--min-instances 1`로 되돌린다. 채점 워커가 0대면 채점 작업이 처리되지 않는다.

## 알려진 함정

- **연결 한도:** Supabase 무료 풀러는 계정당 동시 연결 15개다. 수험생 서버의 연결 수를 올리면 배포 중 옛 버전과 새 버전이 겹쳐 새 버전이 뜨지 못한다. 그때는 수험생 계정 연결을 DB에서 끊고 다시 배포한다(2026-09-27에 한 번 겪었다).
- **경로 변환:** Git Bash는 `/exams` 같은 인자를 Windows 경로로 바꾼다. 배포 스크립트가 `MSYS2_ARG_CONV_EXCL`로 막는다.
- **로그:** 서버 기동 실패는 다음 명령으로 본다.

```bash
gcloud logging read 'resource.type="cloud_run_revision" AND resource.labels.service_name="aim-candidate" AND severity>=ERROR' --project draw-quiz-prod2 --limit 20 --freshness=10m
```
