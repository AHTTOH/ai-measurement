# Claude API 키 최소 확인

> 작성: 2026-09-27 · 절차: `docs/runbook/API-키-연동-절차.md` 2장의 응시용 AI 항목
> 원칙: 신영환 지시 "테스트 아껴써라". 토큰 계산 1회(무료)와 응답 2회만 썼다. 스크립트 `workspace/api-smoke.ts`

## 결과

| 확인 항목 | 결과 |
|---|---|
| 키 인증 | 통과 |
| 토큰 계산(시스템 프롬프트 + CSV 첨부 + 질문) | 2,683토큰 |
| 응답 스트리밍 | 1턴 4.3초, 조각 53개로 흘러나옴. 모델 `claude-sonnet-5`, 정상 종료(`end_turn`) |
| 캐시 적중 | 2턴에서 캐시 읽기 2,681토큰. 1턴에서 캐시 쓰기 2,681토큰. 설계대로 이력을 다시 보내도 새로 계산하는 입력은 2토큰 |
| 답의 정확성 | 부서 6개, 인원이 가장 많은 부서 '개발팀'. 자료와 맞는다 |

| 턴 | 새 입력 | 캐시 쓰기 | 캐시 읽기 | 출력 |
|---|---|---|---|---|
| 1 | 2 | 2,681 | 0 | 336 |
| 2 | 2 | 365 | 2,681 | 289 |

## 관찰

- 한 문장 답을 요청해도 출력이 289~336토큰이었다. effort `medium`에서 thinking이 함께 나온 것으로 보인다. 응시자 토큰 예산은 입력 기준(결정 D2)이라 차감에는 영향이 없지만, 출력 비용은 구현계획 9장 가정(응답 평균 1,200)보다 작은 편이다.

## 하지 않은 것 (비용을 아끼려고 미룸)

- 채점 LLM(구조화 출력)과 배치 채점 실호출
- 레이트 리밋·조직 티어 확인(결정 D15)
- 여러 명 동시 실호출 부하

로컬 `.env`는 계속 `AI_PROVIDER=mock`, `GRADING_LLM_PROVIDER=mock`으로 둔다. 개발·테스트가 실제 API 비용을 쓰지 않게 하기 위해서다. 실제 AI로 돌릴 때만 `anthropic`으로 바꾼다.
