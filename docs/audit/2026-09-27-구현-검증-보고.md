## 검증하지 못한 것과 남은 위험

1. **실제 Claude API 호출 전부**: 스트리밍, 토큰 계산, 캐시 적중, 구조화 출력 채점, 배치, 레이트 리밋·티어. 키 발급 후 확인한다.
2. **LLM 채점 품질**: 골든 세트(사람이 채점한 응시 기록 5~10건)와의 편차 검증이 필요하다.
3. **약 1분마다 몇 초 멈춤**: 부하 중 DB 자동 정리 시각과 겹친다. 원인은 확정하지 못했고, 이 노트북 한 대에서만 재현을 확인했다. 운영과 같은 별도 DB 서버에서 다시 잰다.
4. **여러 PC에 나눈 수험생 서버**: 동작은 한 PC에서 두 프로세스로 검증했다. 서로 다른 PC로 나눴을 때의 처리량 이득은 재지 못했다.
5. **사람이 참여하는 모의고사 리허설**: 절차서만 있고 아직 하지 않았다.
6. **PDF 첨부의 개인정보 패턴**: 패턴 탐지는 본문과 CSV 첨부 텍스트만 본다.
