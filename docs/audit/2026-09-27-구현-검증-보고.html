검증하지 못한 것

  1. 실제 Claude API 호출 전부(스트리밍, 토큰 계산, 캐시 적중, 채점, 배치, 레이트 리밋).
  2. LLM 채점 품질(골든 세트 편차).
  3. 부하 중 약 1분마다 몇 초 멈춤. DB 자동 정리 시각과 겹치며 원인 미확정. 별도 DB 서버에서 다시 잰다.
  4. 여러 PC에 나눈 수험생 서버의 처리량 이득.
  5. 사람이 참여하는 모의고사 리허설(절차서 docs/runbook/모의고사-리허설-절차.md).

결정이 필요한 것: 샘플 루브릭의 '공지 이후 수정' 기준(현재 false), 샘플 시험의 중대 위반 처리(현재 review), API 키와 조직 티어(미발급).
